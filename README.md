# Hangman Game 🎮

A simple, classic **Hangman** game implemented in Python. Guess the secret word one letter at a time before you run out of attempts!

---

## Features

* **Randomized Word Selection**: Picks a random word from a curated list of programming and tech-related terms.
* **Input Validation**: Ensures players enter a single valid alphabetical letter and checks for repeated guesses.
* **Dynamic Display**: Shows current progress with underscores (`_`) for unguessed letters and tracks remaining attempts[cite: 1].

---
